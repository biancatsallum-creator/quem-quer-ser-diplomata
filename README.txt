QUEM QUER SER DIPLOMATA? — CACD Website (version 1)

COMECE A JOGAR
1. Abra index.html em seu navegador no Mac.
2. Ou publique os arquivos index.html, style.css e app.js usando GitHub Pages (veja abaixo).

DOIS MODOS
- Milionário: 15 perguntas, dificuldade crescente, todas as seis disciplinas; 50:50 e Pular (a pergunta pulada vale 0 pontos).
- Por disciplina: 10, 15, 20 ou todas as perguntas disponíveis naquela área.
- Extra: rever erros e consultar/exportar resultados.

BANCO DE PERGUNTAS
140 questões autorais: História do Brasil (28, inclusive Sociologia); História Geral (26); Geografia (20); Economia (20); Direito (20); Relações Internacionais (26). É um banco inicial fundamentado em temas dos materiais enviados, e não uma transcrição integral de todos os documentos. As questões não são oficiais do CACD ou do Cebraspe.

SALVAMENTO
Os resultados são gravados apenas no armazenamento local do navegador utilizado; não sincronizam automaticamente entre dispositivos. Use "Exportar progresso" / "Importar progresso" para transferir o histórico (o arquivo importado substitui o histórico atual).

COMO HOSPEDAR SEM PAGAR DOMÍNIO
1. Acesse https://github.com e crie uma conta (caso ainda não tenha).
2. Crie um repositório público, por exemplo cacd-jogo.
3. Envie index.html, style.css e app.js para a raiz do repositório.
4. Em Settings > Pages, escolha Deploy from a branch, branch main, pasta / (root).
5. Seu endereço será parecido com https://SEU-USUARIO.github.io/cacd-jogo/ .
Um domínio personalizado é opcional e não é necessário para usar o site.

ARQUIVOS
- index.html: site com o banco de perguntas embutido (também pode ser aberto offline)
- style.css: aparência
- app.js: jogo, correção, histórico e exportação
- questions.json: cópia editável do banco de perguntas; o banco embutido em index.html corresponde a este arquivo
- build_bank.py: script gerador do banco (para desenvolvimento)

OBSERVAÇÃO
Este é o lançamento inicial. Pode-se ampliar o banco, validar as questões contra as fontes e refinar a dificuldade após os testes; a interface e os modos já funcionam.
